# ERP 数据字典维护约定

> 目标：让「每个字段都有明确的中文含义」成为可持续、可迭代的工程事实，
> 而不是一次性文档。数据库结构一旦变化，数据字典必须同步更新。

## 1. 架构与单一事实源

| 角色 | 文件 / 位置 | 说明 |
|------|------------|------|
| **权威结构来源** | live `erp_db`（pg_catalog 自省） | 表/字段/类型/可空/默认值/主键的真实来源，永远以它为准 |
| **单一事实源（中文）** | `data-dictionary.json`（仓库根目录） | 人维护的中文映射，**已确认的中文优先级最高** |
| **派生产物 1** | `docs/数据字典.xlsx` | 给人的可读字典（字段级 / 表清单 / 待补充） |
| **派生产物 2** | `scripts/data-dict.comments.sql` | `COMMENT ON` 语句，把中文写进数据库结构 |
| **派生产物 3** | live `erp_db` 的 `pg_description` | 真正落在「数据库表结构」里的中文注释（用 `--apply` 写入） |

> 原则：`data-dictionary.json` 是唯一需要人工维护的文件；
> Excel 与数据库注释都由脚本从它 + 实时结构**重新生成**，不要手改 Excel。

## 2. 文件清单

```
erp_source/
├─ data-dictionary.json          # 单一事实源（人维护中文）
├─ scripts/
│  ├─ gen-data-dict.py          # 生成器（自省 + 合并 + 导出 + 写注释）
│  └─ data-dict.comments.sql    # 生成的 COMMENT ON 语句（可入库执行）
└─ docs/
   └─ 数据字典.xlsx              # 生成的 Excel（多 Sheet）
```

## 3. 日常工作流（表结构变更时必做）

1. **改表**：在 `erp_db` 新增 / 修改 / 删除字段（本项目表结构以直接 DDL 为准）。
2. **校正中文**：打开 `data-dictionary.json`，把相关字段的 `cn` 改成准确中文，并把 `src` 改为 `"confirmed"`。
   - 首次接入本系统时，字段多为 `"推断"`（脚本领域启发式生成，见 `gen-data-dict.py` 的 `KNOWN` 词表），
     请在「待补充」Sheet 中逐条核对，准确后标 `confirmed`。
3. **重跑脚本**：
   ```bash
   python scripts/gen-data-dict.py --apply
   ```
   - 脚本自省最新结构 → 与 `data-dictionary.json` 合并（已确认项优先，缺失项自动启发式生成并标「推断」）
     → 回写 `data-dictionary.json` → 重新生成 `docs/数据字典.xlsx` 与 `scripts/data-dict.comments.sql`
     → `--apply` 把 `COMMENT ON` 写入 `erp_db`。
4. **交付 / 归档**：Excel 与 json 随代码提交；需要发版时按既有 `_export_zip.py` 重新导出 ERP 源码包即可纳入。

## 4. 生成器用法

```bash
python scripts/gen-data-dict.py            # 生成 json + Excel + SQL（不写库）
python scripts/gen-data-dict.py --apply    # 上述 + 把 COMMENT ON 写入 live erp_db
python scripts/gen-data-dict.py --no-write-dict  # 不回写 json（仅查看）
```

环境：依赖 `openpyxl` 与 `psql`（默认 `/opt/homebrew/bin/psql`，可 `PSQL_BIN` 覆盖）；
数据库连接经环境变量 `PGHOST/PGPORT/PGUSER/PGDATABASE/PGPASSWORD`（默认 `localhost:5434/erp:erp_db`）。

## 5. 迭代保证（不会悄悄漏字段）

- 每次重跑都会把**数据库里存在、但字典未确认的字段**自动标为「推断」并落入 Excel 的 **「待补充」Sheet**。
- 因此：任何结构变更若忘了补中文，会在「待补充」中显性暴露，而不是被静默忽略。
- 人工确认后把 `src` 改为 `confirmed`，该字段即移出「待补充」。
