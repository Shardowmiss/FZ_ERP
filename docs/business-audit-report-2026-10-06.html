二、维度①：前端页面 / 路由可达性（#698）

架构根因（务必先理解）：client/src/components/Layout.tsx 全文未 import 也未渲染 <Routes>，而是直接渲染 <TabPageCache/>。因此 app.tsx 中嵌套在 / 下的约 138 条 <Route>实际不参与页面渲染。页面真正由 TabPageCache.getRouteComponent(pathname) 按路径查表渲染（返回 null 即渲染 <NotFound/>）。
可达性真相源 = 菜单 config/menuConfig.tsx + TabPageCache.exactMap / routePermissions + TabsContext.labelMap 三套映射，须人工同步，极易漂移。app.tsx 的 <Route> 仅作“声明”，漏接映射的页面点开即 404。

建议：将该种子行 status 修正为合法值（如 draft 或 booked）并补 dealer_id；或直接删除该行（需用户确认是否保留演示数据）。代价：低（纯数据修正）。
